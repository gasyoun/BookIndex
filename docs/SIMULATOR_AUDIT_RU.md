# Аудит источников интерактивных симуляторов (A5)

Политика: **каждое утверждение должно иметь источник**. Симуляторы
демонстрируют реконструкции исторической лингвистики; они учебно-иллюстративные
и не должны выдавать реконструкцию за непреложный факт (урок проекта: не
представлять реконструкцию как доказанное).

Этот документ — инвентаризация утверждений трёх симуляторов с указанием статуса
источника. Где источник — именованная литература, он назван; где утверждение
стандартно, но точная привязка к странице книги не установлена, оно помечено
**[стандарт]**; где это расширение/приближение — **[иллюстративно]** (требует
проверки специалистом).

Данные симуляторов сейчас захардкожены в `v3_app.js`; ссылки даны на функции.

## 1. Симулятор звуковых законов (`renderPhoneticLawsPanel`)

Корни `*gordъ`, `*melko`, `*dorgъ` → русский / польский / чешский, по шагам.

| Утверждение (поле `law`) | Статус | Источник |
|---|---|---|
| Восточнославянское полногласие (*-or- → -оро-, *-el- → -оло-) | **[стандарт]** | Общая сравнительная славистика; лекции Зализняка «О жизни слов» (книга-источник) |
| Лехитское / чешско-словацкое неполногласие (*-or- → -ro-/-ra-) | **[стандарт]** | То же |
| Спирантизация g → h (чеш./словац./укр.) | **[стандарт]** | То же |
| Падение редуцированных (слабый ъ/ь отпадает) | **[стандарт]** | Закон Гаврлика; ср. `phonetic_laws` |
| Сужение o → ó перед звонким (польск.) | **[стандарт]** | Историческая фонетика польского |
| Долгота/удлинение гласного (чеш. mléko) | **[стандарт]** | Историческая фонетика чешского |
| Флексии прилагательных (-ой/-i/-ý) на конце | **[иллюстративно]** | Морфологическое оформление показано упрощённо — это не звуковой закон |

**Вывод:** звуковые переходы стандартны и корректны; шаги, где смешаны фонетика
и морфология (флексия), стоит пометить как иллюстративные.

## 2. Симулятор акцентологии (`renderAccentReconPanel`, `scholar.accent_paradigms`)

Именные акцентные парадигмы и перемещение ударения по падежам/числам/стадиям.

| Утверждение | Статус | Источник |
|---|---|---|
| Парадигма **A (накоренное/баритонеза)** | авторитетно | А. А. Зализняк, «От праславянской акцентуации к русской» (1985) |
| Парадигма **B (наконечное/окситонеза)** | авторитетно | Там же |
| Парадигма **C (подвижное)** | авторитетно | Там же; «Древнерусские энклитики» (2008) |
| Парадигма **D (энклитический/проклитический контекст)** | **[иллюстративно]** | Расширение для разбора клитик; не входит в классическую трёхакцентную схему — проверить формулировку |
| Парадигма **E (диалектно-исторический слой)** | **[иллюстративно]** | Обобщающий ярлык, не стандартная парадигма — проверить или переименовать |
| Конкретные ударные формы (кни́га, голова́…) и перенос на предлог (на́ городъ) | **[стандарт]** | Зализняк 1985; требует сверки каждой формы |
| Формы двойственного числа | **[стандарт]** | Историческая морфология др.-рус.; сверить |

**Вывод:** A/B/C — прямо из акцентологии Зализняка (надёжно). D/E — нестандартные
расширения, пометить как иллюстративные либо переименовать/убрать. Конкретные
формы требуют построчной сверки специалистом.

## 3. Гидратор орфографии (`hydrateToOldRussian`)

Восстановление др.-рус. написания: ять (ѣ), еры (ъ/ь), юсы (ѫ/ѧ), омега (ѡ).

| Утверждение | Статус | Источник / замечание |
|---|---|---|
| Перечень корней с этимологическим **ять** (хлѣб, вѣра, мѣсто, снѣг, бѣлый, дѣдъ, лѣсъ, цвѣтъ, дѣло, вѣдать…) | **[стандарт]** | Этимологически корректны (ст.-сл./др.-рус. ѣ); ср. словарь Фасмера |
| Корни с **юсами** (ѫ/ѧ — носовые *ǫ/*ę) | **[стандарт]** | Корректно для носовых; сверить список |
| Конечные ъ/ь и юс малый в исходе | **[стандарт]** | Орфография до падения редуцированных |
| **Механизм сопоставления (regex по подстроке)** | **[иллюстративно ⚠]** | Грубое: `/вер/` затронет и «верх/верёвка» (где не было ять), `/бел/` — «белка/обелиск» и т. п. Возможны ложные срабатывания. Инструмент демонстрационный, не нормативный транскриптор |

**Вывод:** сами корни этимологически верны, но **сопоставление по подстроке
приблизительно** и может ошибаться — это главный повод честно пометить гидратор
как учебно-иллюстративный.

## Что сделано в этой итерации (A5)

1. Эта инвентаризация (A5.1).
2. Видимая подпись-источник на всех трёх симуляторах со ссылкой сюда, с явной
   пометкой «учебно-иллюстративный инструмент» (A5.3 — урок Уитни применён).
3. Источники привязаны на **уровне симулятора** (именованная литература:
   акцентология Зализняка 1985/2008; стандартная сравнительная славистика).

## Что осталось (для специалиста)

- Построчная сверка конкретных акцентных форм и список ять/юс-корней.
- Пометки `[иллюстративно]` (флексии в звуковом симуляторе; парадигмы D/E;
  regex-сопоставление гидратора) — исправить, переименовать или явно изолировать.
- При необходимости — точные ссылки на страницы книги-источника в поле
  `source_ref` данных симуляторов.

## Факты: текущая страница vs макет

| | index.html (прод) | mockups/sustainable.html |
|---|---|---|
| Вес | 15,6 КБ | 12,8 КБ (−2,7 КБ) |
| Палитра | пергамент/коричневый (`#fffaf1`/`#5a3818`) | мох/глина (`#f3f1ea`/`#3f5a33`) |
| Схемы | только светлая | светлая + тёмная (`prefers-color-scheme`) |
| Шрифты | Georgia + Arial (системные) | Georgia + system-ui (системные) |
| Веб-шрифты / трекеры / растры в теле | 0 / 0 / 0 (только SVG-марка) | 0 / 0 / 0 (марки нет вовсе) |
| SEO-обвязка | полная: citation_*, CSP-хэши, canonical, hreflang, manifest, иконки, OG, Twitter, JSON-LD | снята (noindex-макет) — при промоции восстанавливается целиком |
| Контент | 6 маршрутов, счётчики 11 лекций · 3376 статей, аппарат, note | тот же, дословно |
| Значок веса страницы | нет | есть (инлайн-скрипт → нужен script-src-хэш) |

**Ключевой факт:** текущая страница УЖЕ почти «sustainable» — 0 веб-шрифтов, 0 трекеров,
только SVG, 15,6 КБ. Реальная пользовательская дельта макета — **тёмная схема**; смена
палитры — вкусовая; −2,7 КБ — косметика.

**Осложнение:** приложение, в которое ведёт главная
([aaz-index.html](https://github.com/gasyoun/BookIndex/blob/main/aaz-index.html) из
`v3_template.html`), — светло-пергаментное и **только светлое** (`--bg: #faf8f3`,
`color-scheme: light`). Мохово-тёмная главная в тёмной системе даст переход
«тёмная дверь → светлая комната» на первом же клике «Открыть BookIndex».

## Варианты

- **A. Adopt** — перенести макет как есть (мох/глина, светлая+тёмная). Плюс: тёмная
  схема, самый лёгкий вариант. Минус: главная хроматически расходится с приложением и
  с книжным брендом «пергамент/коричневый»; переход тёмная→светлая при входе в app.
- **B. Hybrid (рекомендация агента)** — оставить пергаментно-коричневую идентичность
  светлой темы, перенять у макета механику: тёмную схему на токенах текущей палитры
  (тёмно-коричневая, не моховая), system-ui вместо Arial, опционально значок веса.
  Плюс: тёмная схема без разрыва бренда; app остаётся узнаваемым продолжением. Минус:
  дельта против текущей страницы скромная; тёмная главная всё равно ведёт в светлый app,
  пока у приложения нет тёмной темы.
- **C. Reject** — оставить index.html как есть; макет остаётся референсом в `mockups/`.
  Честный вариант: страница уже лёгкая, а тёмную схему логичнее внедрять со стороны
  приложения (v3_template), а не с двери.

Рекомендация — **B**, с оговоркой: если тёмная тема приложения не планируется, то **C**
(дельта adopt/hybrid без неё — в основном вкусовая). Решает человек.

## Что влечёт промоция (A или B) — объём работ уже оценён

Восстановить весь head прода (citation_*, canonical/hreflang, manifest, иконки, OG с
портретом, Twitter, JSON-LD); пересчитать CSP-хэш инлайн-стиля и добавить хэш
скрипта-значка (или сделать значок статичным текстом); ссылки `../` → `./`; убрать
плашку «Макет»; сохранить счётчики и все 6 маршрутов; версия v2.2.0; портрет
`zaliznyak_portrait.png` остаётся только в OG-мета (страница его не грузит — вес 0);
`npm run build` + `check:security:static`. ~1 сессия Fable.

## Как зафиксировать визу

Ответить в любой сессии «H1603: adopt» / «hybrid» / «reject» (или отметить в строке
GTD) — затем перезапустить `/go H1603`: хендофф увидит визу и выполнит перенос.

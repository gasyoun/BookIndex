# Текстовая сверка двух циклов: «Муми-тролль» против ЛЛШ — пересказ или самостоятельный доклад

_Created: 04-09-2026 · Last updated: 04-09-2026_

Полная сверка одиннадцати докладов ЛЛШ (2007–2017) с лекциями школы «Муми-тролль» (2005–2017) по расшифровкам: вопрос каждой пары — июльский доклад является переработкой февральской лекции (или наоборот) или это самостоятельный доклад? Заказ МГ 04-09-2026 («сперва их [четыре пары], а потом всех вообще»); продолжение [CHRONOLOGY_MUMITROLL_LLSH_COUPLES_2026.md](CHRONOLOGY_MUMITROLL_LLSH_COUPLES_2026.md).

**Источники текстов.** ЛЛШ — расшифровки (автораспознание, сырые) с Яндекс.Диска «ААЗализняк-архив» → «обработанные-тексты»/«текст-канал-Алексей-Головастиков» (зарегистрировано в [SHADOW_ASSETS_POINTERS.md](https://github.com/gasyoun/Uprava/blob/main/SHADOW_ASSETS_POINTERS.md)); для 2007/2008/2009/2012/2014/2015 существуют и вычитанные docx-версии — для унификации сверка шла по одному типу источника (ASR), искажения вроде «Момитроль» = «Муми-тролль» учитывались при цитировании. «Муми-тролль» — опубликованные расшифровки elementy.ru (список: [samskrtam.ru/mt](https://samskrtam.ru/mt/)). Метод: полное чтение обеих расшифровок + перекрёстные проверки по 30–40 характерным словам-примерам/фактам/цитатам в обе стороны; решающая улика — собственные авторские отсылки Зализняка к прежним чтениям.

## Выводы

1. **Кулыгин подтверждён по существу.** Настоящие переработки — только 2012 и 2013 (и то «не просто повторение»: половина/большая часть иллюстративного материала заменена). В остальных парах доклады самостоятельные; общее — лекторский скелет и репертуар любимых примеров, а не текст.
2. **Хронологическое соседство ≠ сцепка.** Пары 2011, 2014, 2015 одного года — темы чужие; при этом настоящая преемственность 2015 года идёт к МТ-лекции 2014 года (ударение), а не к бересте того же февраля. Хронология задаёт фон, тексты — вердикт.
3. **«Ещё раз о жизни слов» (2016)** — не пересказ февральской лекции «О жизни слов», а новая серия этимологических эпизодов (ностратика, не/ни, подъезд, берестяные сюжеты); пересечение с лекцией — рамка и один пример («лога/пуха»).
4. **Сериальная структура ударения:** ЛЛШ-2009 → МТ-2014 → ЛЛШ-2015 (углубление финальной задачи МТ-2014) → ЛЛШ-2017 (связывается с ЛЛШ-2009, не с МТ-2014). Сквозная тема с четырьмя самостоятельными реализациями.
5. **Для печати ничего не меняется** — соответствия циклов и не показывались ([H4028](https://github.com/gasyoun/Uprava/blob/main/handoffs/H4028-OxAlpha_BookIndex_print-llsh-bibliography-only_03.09.26.md)); для цифрового спутника вердикт 2011 года означает, что машинную связку «Механизмы экспрессивности» → «О жизни слов» тексты не подтверждают (крест 142/106/129 не пересчитывался — это презентационный слой, зафиксировано здесь).

## Ограничения

1. Сторона ЛЛШ — сырой ASR (2008 — «partial» по каталогу): имена и ударения искажены, проценты покрытия — экспертные оценки агентов, не метрика.
2. Сверка шла по одному типу источника (ASR) для всех одиннадцати; для шести докладов существуют вычитанные docx на диске — при цитировании в печатных текстах сверяться по ним.
3. Тексты «Муми-тролля» — отредактированные публикации elementy (после редактуры), т. е. стороны сравнения имеют разную степень обработки; на вердикты «пересказ/самостоятельный» это не влияет, на дословные совпадения — да.

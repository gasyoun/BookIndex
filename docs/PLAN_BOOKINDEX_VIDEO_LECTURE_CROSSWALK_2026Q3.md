# План: связь видеоархива с главами книги и хронология ЛЛШ

_Created: 14-08-2026 · Last updated: 14-08-2026_

Обложка многослойного плана по заданию `/ask`. Интервью владельца проведено
12–14.08.2026 (прервано таймаутом API, дособрано 14.08.2026); аудит перемерен
заново перед авторингом. Это тот документ, на который указывает стартовая строка
исполняющего handoff'а — остальные четыре слоя лежат отдельными файлами и
перечислены ниже.

**Издание-носитель:** «Из жизни слов и языков» (А. А. Зализняк, корпусный
идентификатор `mumintroll`, 424 с., 2026) — единственная книга корпуса со
статусом `active`.
**Цифровой спутник:** [https://gasyoun.github.io/BookIndex/](https://gasyoun.github.io/BookIndex/).

## Задача в одном абзаце

В книге 11 глав (10 лекций + «От редколлегии»). В каталоге 176 публичных
видеозаписей Зализняка на 214,1 ч. Между ними нет ни одной связи: **ни одна
запись не несёт поля главы или лекции**. Нужно построить доказуемый двусторонний
крест «видео ↔ глава» с точностью до минуты, отдельно показать хронологию
одиннадцати докладов Летней лингвистической школы 2007–2017, вплести материалы
*о* Зализняке (а не только *от* него) — и свести всё это на один печатный
разворот (полосы 4–5) блока-спутника.

## Что изменилось после переизмерения — читать до планирования

Три числа, на которых стоял прежний замысел, оказались неверны. Исполняющий
агент не должен переоткрывать это заново.

| Утверждение | Источник заблуждения | Измерено 14-08-2026 |
|---|---|---|
| «200 видео» | `planned_count: 200` в [data/modules/00-metadata.json](https://github.com/gasyoun/BookIndex/blob/main/data/modules/00-metadata.json) | **176** записей, 214,1 ч. `planned_count` — плановое поле, не факт |
| «расшифровок 27 из 176» | 27 файлов в [data/imports/lectures-v2/transcripts/](https://github.com/gasyoun/BookIndex/blob/main/data/imports/lectures-v2) | **171 из 176 (97 %)** — корпус лежит не в репозитории, а в публичном архиве на Яндекс.Диске |
| «тайм-кодов нет ни у одной записи» | верно для каталога | верно для каталога, но в архиве **171 `.srt`** — тайм-коды уже существуют |

**Главный рычаг связи — не сущности, а серии.** Поштучная разводка через
`related_entities` даёт шум: лекция об арабском языке уезжает в главу
«Историческая лингвистика», а сама глава «Арабский язык» получает ноль
попаданий. Зато 50 записей «История русского ударения» и 32 записи «Строй
ведийского языка / Грамматический строй санскрита» — это два длинных
семинарских цикла, которые целиком отвечают главам 8 и 5. Связывать надо
**серию → главу**, а внутри серии уточнять по тайм-кодам.

## Принятые решения

Строки 1–9 — ответы владельца в интервью. Строки 10–12 помечены явно: это
умолчания, принятые составителем плана, а не ответ человека.

| # | Развилка | Решение | Обоснование |
|---|---|---|---|
| 1 | Что на выходе | И данные, и печатные полосы | Данные переиспользуются приложением; полосы — разовый производственный артефакт |
| 2 | Сколько полос | **2 полосы, один разворот** | Одна тетрадь = 8 полос, разворот читается как целое |
| 3 | Откуда взять полосы | **Заменить полосы 4–5** («Видеокаталог — что это / как пользоваться») | Новый блок содержательно поглощает их: тот же архив, но с привязкой к главам. Полоса 8 остаётся открытой со своими 10 вариантами |
| 4 | Ось соответствия | Все **11** глав, включая «От редколлегии» | Глава 1 получает связи о подготовке издания, а не остаётся пустой |
| 5 | Охват видео | Три дорожки: 10 ЛЛШ · отобранные 30 · все 176. Ребро получает только заслуживающее. Плюс статистика по YouTube | Разные читатели — разная глубина; полнота не должна оплачиваться шумом |
| 6 | Метод связывания | Четыре прохода: KWIC → серии/title+topics → DeepSeek → куратор-гейт | Дёшево-и-доказуемо сначала, LLM только на остатке |
| 7 | ЛЛШ | Отдельный блок-хронология | 11 докладов 2007–2017 — самостоятельный сюжет, не приложение к таблице |
| 8 | Типы связей | Плюс «о Зализняке», другие книги, научные работы, «сиквелы» | Владелец: «вплести выступления *о* Зализняке, а не только *от*» |
| 9 | Дефекты данных | Чинить в этом же PR | Три засорённых поля и подтверждённые дубли — иначе они попадут в печать |
| 10 | Ключ DeepSeek | Из окружения; конфиг — [IndologyScholars/.env](https://github.com/gasyoun/IndologyScholars/blob/main/.env.example) (`DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL`). LLM-проход **обязателен**, не пропускается | *Умолчание составителя.* Владелец: «DeepSeek ключ есть отдельный, не надо без LLM» |
| 11 | Поведение при неоднозначности | Ставить ребро при уверенности; спорное — в секцию «спорные» листа голосования; работу не останавливать, связь не выдумывать | *Умолчание составителя.* Round 5 интервью не состоялся |
| 12 | Забор | См. «Контракт автономности» ниже | *Умолчание составителя* |

## Контракт автономности

Исполняющий агент работает 5–8 часов без человека. Правила ниже обязательны.

**При неоднозначности.** Применить умолчание из плана и продолжить, записав
строку в журнал прогона. Ребро ставится только при уверенности выше порога
(см. [VERIFICATION](https://github.com/gasyoun/BookIndex/blob/main/docs/VERIFICATION_BOOKINDEX_VIDEO_LECTURE_CROSSWALK.md)).
Всё, что ниже порога, не выбрасывается и не досочиняется, а попадает отдельной
секцией «спорные» в лист голосования куратора. **Никогда** не заполнять клетку
догадкой ради полноты покрытия.

**Условия остановки.** Останавливаться только на: (а) недоступности публичного
архива на Яндекс.Диске после трёх попыток; (б) провале смоук-теста DeepSeek
(см. риск R-1); (в) красном CI, который не чинится двумя попытками; (г) любой
операции, которую забор запрещает. Во всех остальных случаях — продолжать.

**Право на коммит.** Handoff'ы H2706 и H2707 уже дают право на
commit → PR → merge без подтверждения. Отдельного разрешения спрашивать не надо.

**Забор — чего не трогать.**

- **Не править** [app_data.json](https://github.com/gasyoun/BookIndex/blob/main/app_data.json) и [aaz-index.html](https://github.com/gasyoun/BookIndex/blob/main/aaz-index.html) напрямую: это генерируемые артефакты. Только `data/modules/*.json` + `npm run data:assemble` + `npm run build`, иначе CI отвергнет рассинхрон.
- **Не переписывать** корпус книги: [20-lectures.json](https://github.com/gasyoun/BookIndex/blob/main/data/modules/20-lectures.json) и указатели 10–14 — только на чтение. Новые связи ложатся в отдельный модуль.
- **Не удалять** записи видеокаталога. Дубли помечаются полем `duplicate_of`; удаление ломает существующие ссылки и счётчики.
- **Не публиковать** наружу: не включать Pages, не менять видимость, не деплоить. Ветка и PR — можно.
- **Не заливать** расшифровки целиком на печатные полосы (права) и не сочинять ISBN, цены и аннотации.

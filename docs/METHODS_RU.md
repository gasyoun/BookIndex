# Методы и провенанс производных данных (A4)

Этот документ честно описывает, **как получены вычисляемые («производные»)
слои** `app_data.json` и какова их эпистемическая надежность. Машиночитаемая
сводка — [`data/provenance.json`](https://github.com/gasyoun/BookIndex/blob/main/data/provenance.json).

Главное: производные слои — это **поисковый, эвристический сигнал**, а не
нормативные утверждения. Они помогают находить связи, но не доказывают их.
(Урок проекта: корпусный/вычисленный сигнал нельзя выдавать за грамматический
или источниковый факт.)

## Слои данных по происхождению

| Слой | Происхождение | Воспроизводим из репозитория? |
|---|---|---|
| Записи указателя (`names`, `toponyms`, `ethnonyms`, `languages`, `lexicon*`, `subject_index`) | извлечены из книги (страницы, контексты) | да — источник = книга; правки через `editorial_flags` |
| `edges` | **производный**: со-упоминание лиц | нет (нет коммитнутого генератора) |
| `language_edges` | **производный**: со-упоминание языков | нет |
| `cross_links` | **производный**: со-упоминание разных типов | нет |
| `semantic_links` | **производный**: схожесть по общим признакам | нет |
| `video_catalog[].related_entities` | курируемое + `src:"transcript"` (C3) | да (C3 — `extract_entities_from_transcripts.py`) |
| `authority` | внешнее: Wikidata/VIAF/GND/GeoNames (A3) | да (`align_authorities.py`, `src:"wikidata-auto"`) |

## Производные слои — что известно о методе

Точные формулы и параметры **не восстановимы из репозитория**: генерирующий
скрипт не закоммичен. Ниже — то, что достоверно следует из описаний в самом
приложении (intro-тексты графов) и из анализа значений.

### `edges` — граф со-упоминаний лиц (60 ребер)

- Поля: `source`, `target`, `weight` (число).
- Метод (из intro приложения): «person-to-person co-mention graph; вес ребра
  отражает, насколько **близко** их упоминания в тексте».
- Из данных: вес — **не** счетчик совпадений. Это мера силы ассоциации: высок,
  когда лица со-упоминаются часто относительно своей индивидуальной частоты
  (PMI-подобно). Пример: «Вернер К.» и «Гримм Я.» встречаются ровно на 3
  страницах, полностью совпадая → вес 49.54; «Иткин А. И.»/«Иткин И. Б.» делят 3
  страницы, но имеют 9 и 32 страницы по отдельности → вес 17.26 (слабее).
- Не восстановимо: функция затухания по близости, нормировочная константа.

### `language_edges` — граф со-упоминаний языков (1931 ребро)

- Поля: `source`, `target`, `weight`.
- Метод (из intro приложения, дословно): «соединены языки, упоминаемые в книге
  близко друг к другу в тексте. Алгоритм **позиционного взвешивания** учитывает
  место упоминания на странице, а не только ее номер — разрыв страницы между
  близкими упоминаниями не наказывается». По умолчанию показываются сильные
  связи (вес ≥ 10).
- Не восстановимо: точная формула позиционного веса.

### `cross_links` — межтиповые со-упоминания

- Структура: `{ <тип источника>: { <head>: [ {head, weight}, … ] } }`,
  типы — names/toponyms/ethnonyms/languages.
- Метод: то же со-упоминание, но между разными типами (имя ↔ топоним и т. д.).
- Используется в карточке (блоки «Связанные имена/топонимы/…»).

### `semantic_links` — схожесть по общим признакам (1767 источников)

- Поля: `head`, `score` (0–1), `shared` (целое).
- Из данных: `shared` — число общих признаков (совместно встречающихся
  элементов / страниц); `score` — нормированная схожесть в (0;1]. `score` не
  является простой функцией одного `shared` (две цели с `shared=7` имеют разные
  score 1.0 и 0.875) → это нормированная мера (типа косинуса/Жаккара) по вектору
  признаков.
- Не восстановимо: конкретная метрика и нормировка.

## Как это подписано в интерфейсе

Производные визуализации (граф связей имен, граф языков) несут подпись о том,
что связи **вычислены автоматически** по со-встречаемости и являются поисковым
сигналом; со ссылкой на этот документ. Внешние авторитетные ссылки (A3) и
видео-связи из расшифровок (C3) помечены в данных (`authority.src`,
`related_entities[].src`) и отличимы от курируемых.

## Что делать дальше (если потребуется воспроизводимость)

Если нужна полная воспроизводимость, derived-слои следует **перегенерировать
коммитнутым скриптом** из `contexts`/`page_list` с явной, задокументированной
формулой, и проставить версию метода в `data/provenance.json`. До тех пор слои
честно помечены как эвристические и не воспроизводимые из репозитория.

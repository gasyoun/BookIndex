Каталог, книга и указатели — **только на чтение**. Всё новое живёт в одном
новом модуле. Это прямо следует из забора и из того, что
[app_data.json](https://github.com/gasyoun/BookIndex/blob/main/app_data.json)
собирается из модулей и сверяется CI на побайтовое совпадение.

## Модель данных

Новый модуль `data/modules/22-crosswalk.json`, ключ владения прописывается в
[data/modules/manifest.json](https://github.com/gasyoun/BookIndex/blob/main/data/modules/manifest.json)
и в `key_order` — иначе сборка его не увидит.

Ребро — не «видео принадлежит главе», а **утверждение с доказательством**:

| Поле | Тип | Смысл |
|---|---|---|
| `edge_id` | строка | Стабильный идентификатор, `<accession>-<chapter>-<pass>` |
| `accession` | строка | Запись каталога, `acc001` … |
| `chapter` | строка | `ch01` … `ch11` |
| `relation` | перечисление | `lecture_of` · `expands` · `sequel_to` · `about_zaliznyak` · `other_book` · `scholarly_work` |
| `pass` | перечисление | `series` · `kwic` · `title_topics` · `llm` · `curator` — какой проход породил |
| `confidence` | 0…1 | Порог и калибровка — в слое проверки |
| `evidence` | объект | См. ниже. **Обязательно.** Ребро без доказательства невалидно |
| `timecode` | строка \| null | `ММ:СС` начала релевантного фрагмента, если проход дал |
| `status` | перечисление | `auto` · `disputed` · `approved` · `rejected` |

`evidence` для каждого прохода:

- `series` — идентификатор цикла и правило (например, «50 записей серии „История русского ударения“ → глава 8»).
- `kwic` — термин указателя, страница книги, файл `.srt`, смещение и цитата ±120 знаков.
- `title_topics` — какие токены заголовка и какие `topics` сработали.
- `llm` — модель с точной версией, промпт-хеш, дословный ответ, `usage`.
- `curator` — идентификатор строки в `decisions.json`.

**Почему доказательство обязательно.** Печатная полоса утверждает связь перед
читателем научно-популярного тома Зализняка; связь, которую нельзя предъявить,
на бумаге неотличима от выдумки. Обязательность поля превращает это из
дисциплины в свойство схемы.

## Четыре прохода: порядок и почему именно такой

Порядок отличается от заявленного в интервью («начать с KWIC»), и это
осознанная правка: **проход по сериям поставлен перед KWIC**. Причина в
измерении — два цикла покрывают 82 из 176 записей (47 %) одним правилом и с
максимальной уверенностью, тогда как KWIC работает поштучно. Дешёвое и
достоверное должно идти первым, иначе KWIC тратит вычисления на то, что уже
решено одним правилом. Владельческое требование «начать с KWIC, там где есть»
сохранено по существу: KWIC остаётся первым *содержательным* проходом и
единственным, дающим тайм-коды.

| # | Проход | Вход | Даёт | Ожидаемый охват |
|---|---|---|---|---|
| A | Серии | заголовки каталога | `lecture_of`, высокая уверенность | ~82 записи |
| B | KWIC | 171 `.srt` + 1299 пар «голова→страницы» | `lecture_of`/`expands` **с тайм-кодом** | наибольшая доля рёбер |
| C | title + topics | `title_display`, `topics` | слабые рёбра на остатке | десятки |
| D | DeepSeek | записи без уверенного ребра после A–C | рёбра + тип связи | остаток |

Проход B — центральный: он единственный производит тайм-коды, а полоса 5
прежнего макета уже обещает читателю метку `▸ ММ:СС`. До сих пор это обещание
было нечем обеспечить (0 тайм-кодов в каталоге); теперь есть 171 `.srt`.

## Связи помимо «от Зализняка»

Требование владельца — вплести материалы *о* нём. Реализуется типом `relation`,
а не отдельным хранилищем:

- `about_zaliznyak` — уже в каталоге: acc019 «Коэффициент достоверности» (2019), acc029 «Истина существует», acc031 «Лингвистический детектив» (2019), acc030 «Наблюдатель» (2019), acc051 прощание, acc038 видеоконференция ко дню рождения. Плюс записи коллег: acc136/acc137/acc163 — доклады А. А. Гиппиуса.
- `other_book` — из [00-metadata.json](https://github.com/gasyoun/BookIndex/blob/main/data/modules/00-metadata.json): «Из заметок о любительской лингвистике» (Альпина, 2025, 208 с.) и «„Слово о полку Игореве“: взгляд лингвиста» (Альпина, 2024, 448 с.).
- `scholarly_work` — библиография по главам уже лежит в [30-scholar.json](https://github.com/gasyoun/BookIndex/blob/main/data/modules/30-scholar.json); заново не собирать.
- `sequel_to` — более поздний доклад на ту же тему. Самый чистый пример уже виден в хронологии ЛЛШ: «Контуры истории русского ударения» (2009) → «Эпизод из истории русского ударения» (2015) → «Живые механизмы современного русского ударения» (2017).

Поиск в вебе новых материалов *о* Зализняке — допустим, но результат ложится
тем же ребром с `evidence.source_url` и обязательно проходит куратор-гейт.

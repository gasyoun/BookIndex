## Пороги уверенности

Один порог на всё не годится: цена ошибки на печатной полосе выше, чем в
приложении с кнопкой «сообщить об ошибке».

| Проход | Порог `auto` | Ниже порога | В печать (полосы 4–5) |
|---|---|---|---|
| A — серии | 0.90 | — | да |
| B — KWIC | 0.75 | `disputed` | да, при ≥ 0.85 |
| C — title + topics | 0.60 | `disputed` | нет — только приложение |
| D — DeepSeek | 0.80 | `disputed` | **только после `approved` куратором** |

Ни одно ребро от LLM не попадает на бумагу без человеческого «да». Это не
недоверие к модели, а свойство носителя: печать неисправима.

## Критерии приёмки

| # | Что доказываем | Команда или проверка | Порог |
|---|---|---|---|
| A1 | Архив проиндексирован полностью | `python scripts/crosswalk/index_yandex_archive.py` | 1569 файлов, из них 213 `.srt`/`.vtt` |
| A2 | Записи привязаны к файлам | `python scripts/crosswalk/match_catalog_to_archive.py` | `.srt` у ≥ 165 из 176; ожидание — 171 |
| A3 | Каждое ребро доказуемо | `python scripts/crosswalk/validate_edges.py` | 0 рёбер без непустого `evidence` |
| A4 | Тайм-коды в границах записи | тот же скрипт | 0 тайм-кодов вне `duration_seconds` |
| A5 | Глава существует | тот же скрипт | все `chapter` ∈ ch01…ch11 |
| A6 | Ни одна глава не осталась пустой | тот же скрипт | ≥ 1 ребро на каждую из 11, включая ch07 «Арабский язык» и ch01 «От редколлегии» |
| A7 | Шум не вернулся | ручная сверка 10 случайных рёбер | арабская лекция acc001 **не** ведёт в ch03/ch04 |
| A8 | Модули и монолит совпадают | `npm run data:assemble` затем `git diff --exit-code app_data.json` | чисто |
| A9 | Артефакт пересобран | `npm run build` затем `git diff --exit-code -- aaz-index.html` | чисто |
| A10 | Содержимое валидно | `python scripts/validate_content.py app_data.json` | выход 0 |
| A11 | Кодировки целы | `python scripts/check_encoding.py` и он же по `docs/*.md` | выход 0 |
| A12 | Ничего не сломано | `python runtime_test.py`, `npm run check` | зелено |
| A13 | Дефекты волны 0 закрыты | сверка каталога | `type` чист у acc139/145/146; тема `ЛЛШ` у 12; `duplicate_of` у acc040 |
| A14 | Лист голосования пригоден | открыть `review/crosswalk_gate.html` двойным щелчком | три секции, выгрузка `decisions.json` работает |

`A6` — не формальность. До этой работы главы «Арабский язык» и «Берестяные
грамоты» получали **ноль** попаданий при сущностной разводке, хотя записи по обеим
темам в архиве есть. Пустая глава означает, что проход не сработал, а не что
материала нет.

## Регрессия против прошлого аудита

Три скрипта прошлой сессии `/ask` лежат в
[docs/history/](https://github.com/gasyoun/BookIndex/blob/main/docs/history) и
запускаются как регрессия — их числа не должны разъехаться:

```sh
python docs/history/audit_video_lecture_crosslink_h_ask.py
python docs/history/audit_llsh_and_bibliography_h_ask.py
python docs/history/audit_crosswalk_derivability_h_ask.py
```

Опорные значения на 14-08-2026: 176 записей / 214,1 ч; 11 глав; темы
`русистика` 50, `санскрит` 32, `ЛЛШ` 10, `береста` 8, `интервью` 1, без темы 75;
1299 пар «голова → страницы».

## Реестр рисков

| # | Риск | Вероятность | Что делает агент |
|---|---|---|---|
| **R-1** | **Инференс DeepSeek не проходит из ограниченного окружения.** Докстринг [openmodel_client.py](https://github.com/gasyoun/IndologyScholars/blob/main/tools/openmodel_client.py) прямо предупреждает: TLS-сбросы и подставные 404 при живом `GET /v1/models` | средняя | Смоук **до** массового прогона. Провал — очередь в `pass_d_pending.json`, шаги 7–8 идут дальше, проход D доигрывается с чистого выхода. Проход не отменяется |
| **R-2** | Публичная шара переедет или закроется | низкая | Индекс шага 1 закоммичен, поэтому работа переживает пропажу источника. Отметить в [Uprava/SERVER_OUTAGES.md](https://github.com/gasyoun/Uprava/blob/main/SERVER_OUTAGES.md) |
| **R-3** | Качество ASR неровное. В реестре владельца 119 «готово», но десятки помечены «зациклен фрагмент», «распознаны первые 20 мин», «видео без звука» | **высокая** | Зацикленные фрагменты дают ложные KWIC-попадания. Переносить пометки владельца в `evidence.asr_quality`; при известном дефекте резать уверенность вдвое |
| **R-4** | Порог похожести 0.62 склеит соседние лекции одного цикла («Лекция 14» ↔ «Лекция 15») | средняя | В цикле сверять номер лекции и дату, а не только заголовок |
| **R-5** | Схлопывание дублей по длительности удалит разные доклады | средняя | Ни одно схлопывание не автоматическое; все семь пар — в лист голосования. Три из семи почти наверняка совпадение |
| **R-6** | Рассинхрон `app_data.json` и модулей уронит CI | средняя | A8/A9 в каждом коммите, не в конце |
| **R-7** | На полосу попадёт непроверенное ребро | низкая | Волна 3 читает только `status: approved` |

## Что требует человека

Ровно одна точка — куратор-гейт волны 2. Человек открывает
`review/crosswalk_gate.html`, голосует и отдаёт `decisions.json`. Это не подпись
и не формальность: без неё ни одно ребро от LLM не попадает на бумагу, а семь пар
дублей остаются неразобранными. Всё остальное — машинное. Печать (волна 3)
ждёт этого файла; данные и приложение — нет.

- **Гейт «build output in sync» снова зелёный: пререндер больше не вшивает в страницы дату сборки (CI main падал на нём с 05-09 по 23-09-2026).** Шаг «Ensure committed build output (aaz-index + prerendered pages) is in sync» падал не из-за пропущенной пересборки, а из-за недетерминизма: `renderCitationWidget()` в `scripts/prerender.mjs` писал в ГОСТ-цитату каждой из 689 пререндеренных страниц «дата обращения» из `new Date()`, так что со следующего же календарного дня после пересборки (04.09.2026) любая сборка расходилась с закоммиченным выводом. Дата теперь закреплена константой `PRERENDER_CITATION_ACCESS_DATE` (= закоммиченная `04.09.2026`, поэтому страницы не меняются); статический текст нужен только читателям без JS и краулерам — в браузере `wireCitationWidget()` при гидратации подставляет текущую дату посетителя. Регрессионный тест `tests/unit/test_prerender_determinism.py` не даёт вернуть часы в пререндер.
